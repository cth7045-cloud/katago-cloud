오픈소스 고지

KataGo Cloud는 아래 오픈소스 소프트웨어와 공개된 신경망·글꼴을 사용합니다. 만든 분들께 감사드립니다.

사이트

LizzieYzy Next — GNU GPL v3.0

github.com/wimi321/lizzieyzy-next

분석 화면(analysis.html)과 로그인 화면의 바둑판 그림(hero.js)은 LizzieYzy Next의 그리기 규칙(BoardRenderer, GlassEffectRenderer, LizzieFrame, WinrateGraph, VariationTree)을 옮겨 만들었고, 바둑판·돌·배경 그림(assets/board.png, black0.png, white0.png, background.jpg)은 LizzieYzy Next에서 가져왔습니다. 그래서 이 파일들은 GNU GPL v3.0으로 배포합니다.

소스 코드: 이 파일들은 압축·변환하지 않은 원본 그대로 제공되며, 전체 사이트 코드는 공개 저장소 github.com/cth7045-cloud/katago-cloud에 있습니다. 자세한 내용은 assets/NOTICE.txt, 전문은 assets/LICENSE-GPL-3.0.txt를 보세요.

GPU에서 도는 것

GPU를 빌리면 그 GPU 서버에 아래 프로그램과 신경망을 내려받아 실행합니다. 회원의 기기로 배포되는 것은 없습니다.

KataGo — MIT License

github.com/lightvector/KataGo · Copyright David J Wu ("lightvector") 및 KataGo 기여자

바둑 분석 엔진입니다. 공식 릴리스(CUDA 버전)를 그대로 받아 씁니다.

KataGo 신경망 (모델)

CNN b18·b28·b40, b28 Muon은 katagotraining.org(KataGo 분산 학습)에서, Transformer 소형·중형·대형은 KataGo 공식 릴리스에서 받습니다. 사용 조건은 katagotraining.org 신경망 라이선스와 KataGo 저장소의 안내를 따릅니다.

cloudflared — Apache License 2.0

github.com/cloudflare/cloudflared · Copyright Cloudflare, Inc.

GPU와 분석 화면을 잇는 암호화 연결(Cloudflare Tunnel)에 씁니다. 공식 릴리스를 그대로 받아 씁니다.

Python, Ubuntu 패키지

GPU 안의 중계 프로그램은 Python 표준 라이브러리만으로 만들었고(PSF License), 설치에 쓰는 curl·unzip 등 Ubuntu 패키지는 각자의 라이선스를 따릅니다.

글꼴·라이브러리

supabase-js — MIT License

github.com/supabase/supabase-js · Copyright (c) 2020 Supabase

로그인과 데이터 읽기·쓰기에 씁니다(jsDelivr에서 받음).

SUIT — SIL Open Font License 1.1

github.com/sun-typeface/SUIT · Copyright sun-typeface

사이트 전체의 한글 글꼴입니다(jsDelivr에서 받음).

Open Sans — SIL Open Font License 1.1

fonts.google.com/specimen/Open+Sans · Copyright The Open Sans Project Authors

바둑판의 승률·방문 수 숫자 글꼴입니다(LizzieYzy Next와 같음, Google Fonts에서 받음).
