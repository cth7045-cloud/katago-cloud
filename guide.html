사용 가이드

KataGo Cloud는 GPU를 잠깐 빌려 KataGo를 돌리고, 브라우저에서 YZY(LizzieYzy)와 같은 화면으로 바둑을 분석하는 서비스입니다. 폰·태블릿·PC 어디서든 됩니다.

시작하기

  1. 회원가입 — 첫 화면에서 회원가입을 누르고 이름, 이메일, 비밀번호(8자 이상)를 넣습니다. 가입하면 바로 로그인됩니다.
  2. 충전 — 요금은 미리 충전한 잔액에서 나갑니다. 위쪽 막대의 충전을 누르면 카카오톡 오픈채팅 QR 코드가 나옵니다(폰에서는 카카오톡 오픈채팅 열기). 오픈채팅으로 관리자에게 충전할 금액을 알려 주세요. 충전되면 GPU 대여 화면 위쪽 내 잔액에 금액이 보입니다.
  3. GPU 시작 — 처음 화면의 GPU 대여를 누르고 GPU 목록에서 하나를 골라 이 GPU로 시작을 누릅니다.
  4. 분석 화면 열기 — 보통 1~3분 뒤 준비가 끝나면 분석 화면 열기 버튼이 나타납니다. 새 탭에서 분석 화면이 열립니다. 기다리는 동안 다른 탭이나 앱에 가 있어도 됩니다 — GPU를 시작할 때 알림을 허용하면(또는 내 GPU 칸의 🔔 준비되면 알림 받기) 준비가 끝나거나 실패했을 때 알림이 오고, 탭 제목에도 ●가 붙습니다(사이트 탭을 열어 둔 동안만).
  5. GPU 종료 — 다 쓰면 반드시 GPU 종료를 누르세요. 그 순간 요금이 멈춥니다.

GPU 빌리기

GPU 대여 화면의 GPU 시작 칸에는 지금 빌릴 수 있는 GPU 중 가격에 비해 성능과 안정성이 좋은 것만 추려서 보여 줍니다. 반응이 느린 먼 지역(중국·호주·미국·유럽 등)은 뺐습니다.

칸뜻
지역GPU가 있는 곳입니다. 한국에 가까울수록 착수 후 분석이 빨리 뜹니다.
GPU그래픽카드 이름입니다. 숫자가 클수록(예: 3060 < 5070 Ti < 5090) 대체로 빠르고 비쌉니다.
VRAM그래픽카드 메모리입니다. 목록에 있는 GPU는 모두 KataGo에 충분합니다.
시간당1시간 쓸 때의 요금입니다. GPU 값에 저장 공간 값까지 넣은 금액이고, 실제로는 쓴 분만큼만 나갑니다.
성능/$가격 대비 성능입니다. Vast가 잰 GPU 성능 점수를 시간당 요금(달러)으로 나눈 값이라, 높을수록 같은 돈으로 더 많이 탐색합니다. 싸고 적당히 빠른 GPU를 고를 때 보세요.
CPUCPU 코어 수입니다. 폰에서는 숨겨집니다.

모델 고르기

목록 위 모델에서 KataGo 신경망을 고릅니다. 기본값은 Transformer 대형입니다. 큰 모델일수록 한 수를 더 정확하게 보지만 설치가 조금 오래 걸리고 1초에 볼 수 있는 수(visits/s)가 줄어듭니다. 잘 모르겠으면 기본값을 쓰세요.

시작부터 준비까지

줄을 누르면 그 아래에 이 GPU로 시작이 나타납니다. 누르면 요금을 한 번 더 확인하고, GPU를 빌린 뒤 세 단계가 차례로 채워집니다.

  1. GPU 빌리기·부팅 — GPU를 빌리고 켜는 중입니다.
  2. KataGo 설치·검증 — GPU가 KataGo와 모델을 받아 설치하고, 분석 엔진을 켜서 실제로 분석해 보며 제대로 도는지 확인합니다. 그동안 웹 연결도 함께 준비합니다.
  3. 분석 준비 완료 — 분석 화면 열기가 빛나며 나타납니다.
고른 GPU를 다른 사람이 먼저 빌려 가면, 같은 지역의 같은 GPU 중 시간당 요금이 같거나 10원까지 비싼 것을 자동으로 대신 빌립니다(최대 4대까지 시도). 그래도 없어서 다른 사람이 먼저 빌려 갔다는 안내가 뜨면 요금은 나가지 않았습니다. 목록이 새로 고쳐지니 다른 GPU를 고르세요. 빌리지 못한 GPU는 1시간, 빌렸지만 준비에 실패한 GPU는 24시간 동안 목록에서 빠집니다.

한 계정은 한 번에 GPU 하나만 쓸 수 있습니다. 쓰는 동안에는 GPU 대여 화면에 내 GPU 카드가 보이고, 지금까지 쓴 시간과 요금이 표시됩니다.

요금과 자동 종료

  • 요금은 GPU를 빌린 순간부터 1분 단위로 잔액에서 차감됩니다. 준비하는 1~3분도 포함됩니다.
  • 쓴 시간만큼 목록의 시간당 요금 그대로 계산합니다. 예를 들어 시간당 170원 GPU를 30분 쓰면 85원입니다(1원 미만은 올림).
  • 시작하려면 잔액이 그 GPU로 약 15분 쓸 만큼은 있어야 합니다.
  • 준비 도중 실패하면(설치 실패·준비 시간 초과 등, 한 번도 "사용 가능"이 되지 못한 경우) GPU가 삭제된 뒤 그 대여 요금을 전부 자동으로 돌려드립니다. 사용 내역에 "준비 실패 환불"로 보입니다. 준비 중에 직접 종료한 경우는 쓴 시간만큼 나갑니다.

GPU가 스스로 꺼지는 경우

켜 둔 채 잊어버려도 요금이 계속 나가지 않도록, 아래 경우에는 GPU가 자동으로 꺼지고 삭제됩니다.

  • 10분 동안 분석 요청이 없을 때 — 분석 화면 탭만 열어 두는 것은 사용으로 치지 않습니다. 수를 두거나 넘기며 분석하면 계속 켜져 있습니다. 자동분석·대국 리포트·기보 분석이 도는 동안은 오래 걸려도 사용 중으로 칩니다.
  • 잔액이 0원이 됐을 때
  • 준비가 너무 오래 걸릴 때 — GPU에 문제가 있는 것으로 보고 끕니다.

직접 끄기

GPU 대여 화면의 GPU 종료, 또는 분석 화면의 GPU 종료를 누르세요. 분석 화면에서는 PC·태블릿 가로 화면이면 위쪽 막대에, 폰 세로 화면이면 ☰ 메뉴 맨 위 GPU 칸에 있고, 지금까지 쓴 시간과 요금도 함께 보입니다(사이트에 로그인된 브라우저에서만). GPU 없이 연 분석 화면(위쪽 분석 화면 링크, 내 기보 열기 등)에서도 켜 둔 GPU가 있으면 같은 자리에 켜진 GPU로 보이고, 이 GPU로 연결(새 탭)이나 GPU 종료를 누를 수 있습니다. 삭제가 확인되면 요금이 멈추고, 사용 내역은 내 정보에서 볼 수 있습니다.

다 쓰면 바로 끄는 것이 가장 쌉니다. 브라우저 탭을 닫는 것만으로는 GPU가 곧바로 꺼지지 않습니다(10분 뒤 자동 종료).

분석 화면

배치는 YZY와 같습니다. PC·태블릿 가로 화면에서는 아래처럼 보입니다.

  1. 위쪽 막대 — 파일(SGF·내 기보·오답노트), 내 기보 저장(사이트에 로그인된 브라우저에서만), AI대국, 기보 불러오기, 대국 리포트, 접바둑·덤, 형세·후보수보기, 돌 놓기(흑·백·번갈아). 오른쪽 끝은 초당 탐색 수(visits/s), GPU 사용 시간·요금과 GPU 종료(로그인된 브라우저에서만), 연결 상태(초록 점 = GPU와 연결됨, 숫자 = 응답 시간).
  2. 사석·덤 — 흑·백이 따낸 돌 수, 덤, 한국룰. 가운데 초록 점은 지금 차례입니다.
  3. 승률 칸 — 왼쪽 흑·오른쪽 백 승률과 수 번호, 리드(몇 집 앞서는지), 마지막 수로 승률·집을 얼마나 잃었는지.
  4. 승률 그래프 — 파란 선은 흑 승률, 분홍 선은 리드. 빨간 점이 지금 수이고, 그래프를 누르면 그 수로 갑니다.
  5. 대국 정보 — 대국자·결과·날짜·덤, 엔진 상태(생각 중/멈춤), 지금 국면의 승률·리드·방문 수, 기보 댓글.
  6. 바둑판 — 후보수(색 동그라미)와 참고도. 읽는 법은 후보수 읽는 법을 보세요.
  7. 변화도 — 기보의 갈래. 점을 누르면 그 수로 갑니다.
  8. 후보표 — 후보수를 순서대로: 승률, 비짓(탐색 수), 비중(탐색 비율 %), 리드.
  9. 미리보기 판 — 후보표에서 고른 수의 예상 수순을 번호로 보여 줍니다.
  10. 아래쪽 막대 — 분석 시작/정지, 자동분석, 수순 이동, 패스, 주 변화로 지정, 수순·좌표, 바둑판초기화, 지우기.

휴대폰(세로 화면)

세로 화면에서는 바둑판을 크게 보여 주기 위해 위쪽에는 초당 탐색 수(visits/s)만 두고, 바둑판 → 승률 막대 → 수순 이동 버튼 순으로 놓습니다. 나머지 기능은 모두 오른쪽 아래 ☰ 메뉴 안에 있습니다. 메뉴는 GPU·기보·대국·분석·보기·편집 여섯 칸으로 나뉩니다.

  • 맨 위 GPU 칸에서 연결 상태(응답 시간, 여러 기기면 기기 수), 지금까지 쓴 시간·요금을 보고 GPU 종료를 누를 수 있습니다.
  • 보기 칸에서 승률 막대와 승률 그래프를 켜고 끌 수 있습니다(기본: 막대 켬, 그래프 끔).
  • 수순·좌표·세기·돌 놓기 버튼은 눌러도 메뉴가 닫히지 않아 여러 번 바꿔 볼 수 있습니다.

분석 기능

분석 시작

▶ 분석 시작을 누르면 지금 보는 국면을 멈출 때까지 계속 분석합니다. 수를 넘기면 새 국면을 바로 분석합니다. 위쪽 막대의 N visits/s는 1초에 몇 번 탐색하는지입니다.

자동분석과 세기

자동분석은 첫 수부터 지금 보는 수까지 모든 국면을 차례로 분석해 승률 그래프를 채웁니다. 세기는 네 가지입니다.

세기한 수에 쓰는 탐색
빠름250 visits — 대강 흐름을 볼 때
보통500 visits — 기본값
정밀1000 visits — 오래 걸리지만 더 정확
초정밀5000 visits — 정밀보다 약 5배 오래 걸림(한 판에 수십 분이 걸릴 수 있음). 중요한 대국을 꼼꼼히 볼 때
  • PC 가로 화면에서는 자동분석을 누르면 세기 목록이 뜨고, 고르는 순간 시작합니다. 폰에서는 메뉴의 분석 칸에 세기 버튼이 따로 있습니다.
  • 진행 중에는 버튼이 ■ 자동분석 취소 n/N으로 바뀌고, 누르면 도중에 멈춥니다. 그때까지 분석된 수의 결과는 남습니다.
  • 고른 세기 이상으로 이미 분석된 수는 건너뜁니다. 모두 분석돼 있으면 버튼이 재분석으로 바뀌고, 누르면 전부 다시 분석합니다.
  • 세기는 자동분석과 대국 리포트가 함께 씁니다. 그래서 자동분석을 해 두면 대국 리포트는 기다리지 않고 바로 나옵니다(반대도 마찬가지).

  • 결과가 있을 때 다시 분석을 누르면 지금 세기로 모든 수를 다시 분석합니다. 세기가 높을수록 손해 값이 덜 흔들립니다.
손해는 AI가 본 형세 차이라 검토 참고용입니다. 이미 크게 이기거나 진 판에서는 큰 손해도 승률이 거의 안 변해서 등급이 낮게 나올 수 있습니다.

기보

파일 메뉴

  • SGF 열기 — 내 기기의 SGF 파일을 엽니다. 컴퓨터에서는 SGF 파일을 분석 화면에 끌어다 놓아도 열립니다(언제든, 한 번에 한 개).
  • SGF 저장 — 지금 기보를 SGF로 내려받습니다. 분석값(승률·리드·후보수 20개와 수순)도 함께 저장돼서, 다음에 열면 다시 분석하지 않아도 그래프와 후보수가 보입니다.
  • SGF 복사 / 붙여넣기 — 클립보드로 주고받습니다. 다른 프로그램이나 메신저의 SGF를 붙여넣을 때 편합니다.
  • 내 기보 열기 — 아래 '내 기보'를 보세요. 저장은 파일 메뉴가 아니라 위쪽 막대의 내 기보 저장 버튼입니다.
  • 오답노트에 담기 / 오답노트 — 아래 '오답노트'를 보세요.

내 기보

분석한 기보를 사이트 계정에 저장해 두고 언제든 다시 여는 기능입니다. 위쪽 막대(폰도 위쪽)의 파란 내 기보 저장 버튼을 누르면 지금 기보가 분석값(승률·리드·후보수 20개와 수순)과 함께 저장됩니다. 저장 창에서 기보 저장 · 오답노트 만들기 가운데 체크한 것만 만들어집니다. 오답노트 만들기를 체크하면 이 기보의 실수 목록이 열려 담을 실수를 바로 오답노트에 넣을 수 있습니다(분석된 수가 있을 때만). 버튼을 누를 때만 저장되고, 계정마다 100판까지 저장할 수 있습니다.

  • GPU 없이 보기 — 처음 화면의 내 기보를 눌러 나오는 목록에서 기보를 누르면 GPU를 켜지 않아도 저장된 승률 그래프·후보수·수순을 보며 복기할 수 있습니다. 새로 분석하지는 않습니다.
  • 이어서 분석 — GPU가 켜져 있을 때 기보를 누르면(또는 분석 화면의 내 기보 열기) 그 GPU로 열립니다. 자동분석·대국 리포트는 이미 그 세기 이상으로 분석된 수를 건너뛰니, 모자란 부분만 분석됩니다.
  • 다 끝나면 GPU 끄기 — GPU가 켜져 있으면 저장 창에 이 칸이 보입니다(창을 열 때마다 꺼진 상태). 체크하면 저장이 끝나는 대로(오답노트 만들기도 골랐으면 담기 창을 닫는 대로) GPU를 끄고 삭제합니다. 자동분석이나 대국 리포트가 도는 중이면 버튼이 끝나면 저장으로 바뀌고, 분석이 끝까지 끝나면 그때 저장하고(오답노트는 담기 창에서 마지막으로 고른 기준으로 바로 담음) GPU를 끕니다. 분석을 취소하거나 연결이 끊기거나 다른 기보를 열면 저장도 끄기도 하지 않습니다. 초정밀 자동분석을 걸어 두고 자리를 비울 때 쓰세요.
  • 기보 추가(GPU 없이 기록) — 내 기보 목록 위의 ＋ 기보 추가를 누르면 새 탭에 빈 판이 열리고 기보 정보 창(흑·백 이름, 날짜, 결과)이 뜹니다. 판을 눌러 흑·백 차례로 두고(잘못 둔 수는 그 수에서 아래쪽 분홍 지우기를 누르면 그 수부터 뒤가 지워집니다) 내 기보 저장을 누르면 저장됩니다. GPU를 켜지 않으니 요금이 들지 않고, 나중에 GPU를 켜고 목록에서 열면 이어서 분석할 수 있습니다. 대국자·결과는 파일 → 기보 정보… 또는 판 옆 대국자 칸을 눌러 언제든 고칠 수 있습니다.
  • 분류 — 기보를 내가 정한 분류(예: 타이젬 기보, 오프라인 기보)로 나눠 둡니다. 처음 화면의 내 기보를 누르면 분류가 카드로 보입니다(전체 기보 · 내가 만든 분류들 · 분류 없음, 카드마다 판 수와 최근 기보). ＋ 새 분류 카드로 만들고(30개까지), 카드를 누르면 그 분류의 기보 목록이 열립니다. 목록의 분류 칸에서 기보를 다른 분류로 옮기고, 분류 목록 위의 이름 바꾸기·분류 지우기로 분류를 고칩니다. 분류를 지워도 안의 기보는 지워지지 않고 '분류 없음'으로 갑니다. 분류를 연 채 기보 추가를 누르면 그 분류로 저장되고, 분석 화면의 내 기보 저장 창에서도 분류를 고르거나 새로 만들 수 있습니다. 기보 분석(여러 기보)에서도 '저장할 분류'를 고를 수 있습니다.
  • 기보 찾기 — 기보가 2판 이상이면 목록 위에 찾기 칸이 나옵니다. 제목·대국자 이름·대국 날짜·결과로 찾고, 띄어 쓴 낱말은 모두 들어간 기보만 보입니다(예: 홍길동 2026-09, 흑 불계, 무승부). 최근 저장순·대국 날짜순·제목순·수 많은 순으로 정렬하고, 분석된 것만을 켜면 분석값이 저장된 기보만 봅니다. 분석 화면의 내 기보 열기 창에도 같은 찾기 칸이 있습니다.
  • 다시 저장 — 내 기보에서 연 기보를 저장하면 덮어쓰기와 새로 저장 중에서 고릅니다.
  • 공유 — 내 기보 목록에서 기보의 공유 → 링크 만들기를 누르면 읽기 전용 링크가 생깁니다. 복사(폰은 보내기…로 카카오톡 등)해서 보내면, 받은 사람은 로그인이나 GPU 없이 그 기보와 저장된 분석(승률 그래프·후보수)을 볼 수 있습니다. 받은 사람이 회원이면 내 기보 저장으로 자기 기보에 복사할 수 있습니다. 공유 중인 기보는 목록에 초록색 공유 중으로 보이고, 눌러서 공유 끄기를 하면 그 링크는 더 이상 열리지 않습니다. 대국자 이름·결과·날짜도 함께 보이니, 다른 사람의 이름이 든 기보는 주의해서 공유하세요.
  • 지우기 — 처음 화면 '내 기보' 목록이나 분석 화면 '내 기보 열기' 목록의 삭제. 되돌릴 수 없습니다(공유 링크도 함께 사라집니다).

기보 분석

분석 화면을 열지 않고 SGF 기보 여러 개를 한꺼번에 분석해 내 기보에 저장하는 기능입니다. 처음 화면의 기보 분석을 누르면 맨 위 기보 첨부 칸에 기보를 올리고, 그 아래에서 GPU를 고를 수 있습니다(이미 켜 둔 GPU가 있으면 그대로 씀).

  • 기보 파일 추가로 SGF 파일을 여러 개 고르고(여러 번 눌러 더할 수 있음, GPU 준비 중에도 미리 골라 둘 수 있음, 컴퓨터에서는 파일들을 이 화면에 끌어다 놓아도 됨 — 분석이 도는 중에는 안 받음), 세기(빠름·보통·정밀·초정밀)를 고른 뒤 분석 시작을 누르세요. 기보마다 본선 전체를 자동분석과 같은 방식으로 분석하고, 끝나는 대로 내 기보에 저장합니다.
  • 저장 제목은 대국자 이름과 날짜(없으면 파일 이름)입니다. 목록에 기보마다 진행 상황(분석 중 n/N · 저장함 · 오류)이 보입니다.
  • GPU가 준비되기 전에도 시작을 예약할 수 있습니다. GPU를 빌리는 중(부팅·설치 중)에 준비되면 분석 시작을 누르면, 준비되는 순간 저절로 분석을 시작합니다. 그동안 내 기보·학습방 같은 다른 화면으로 가도 됩니다. 다시 누르면 예약이 풀리고, GPU가 꺼지면 예약도 취소됩니다.
  • 끝날 때까지 그 창을 열어 두세요. 창을 닫거나 새로고침하면 멈춥니다. 도중에 멈추려면 분석 취소 — 이미 저장된 기보는 남고, 다시 분석 시작을 누르면 저장 안 된 기보만 처음부터 분석합니다.
  • 오답노트도 만들기 — 체크하면 기보를 저장하면서 실수를 오답노트에 바로 담습니다. 누구의 실수를 담을지(흑·백 모두 / 흑만 / 백만 / 내 이름 쪽만)와 기준(작은 실수까지 · 실수 · 큰 실수만)을 고르세요. '내 이름 쪽만'은 적어 둔 이름(예: 한큐 닉네임)이 흑·백 대국자 이름에 들어 있는 쪽의 수만 담고, 이름이 어느 쪽에도 없는 기보는 건너뜁니다. 이미 담긴 문제는 다시 담지 않습니다.
  • 다 끝나면 GPU 끄기 — 체크해 두면(기본) 모든 기보가 끝나는 대로 GPU를 끄고 삭제해 요금이 멈춥니다. 분석 취소로 멈췄을 때는 끄지 않습니다.
  • 같은 파일을 다시 분석하면 내 기보에 한 판이 더 저장됩니다(계정마다 100판까지).

오답노트

분석한 기보에서 내가 둔 실수를 문제로 모아 두고, 다시 풀어 보며 익히는 기능입니다. GPU 없이도 풀 수 있습니다.

  • 담기 — 기보를 자동분석한 뒤 파일 메뉴(폰은 ☰ 메뉴의 기보 칸)의 오답노트에 담기를 누릅니다. 흑·백 중 누구의 실수인지와 기준(작은 실수까지 / 실수 / 큰 실수만)을 고르면, 그만큼 손해 본 수가 둔 수·AI 최선·손해 집 수와 함께 나옵니다. 고른 수들이 문제가 됩니다. 이미 담긴 문제는 건너뛰고, 계정마다 300문제까지 담을 수 있습니다.
  • 풀기 — 파일 메뉴의 오답노트나 처음 화면 학습방의 복습하기를 누릅니다. 실수하기 직전 국면이 후보수 없이 나오면 바둑판을 눌러 답합니다. AI가 가장 먼저 고른 수나, 그 수와 1.5집(승률 3%) 안쪽인 수를 두면 정답입니다.
  • 초반 · 중반 · 종반 — 문제는 실수한 수 번호로 나뉩니다. 50수까지 초반, 150수까지 중반, 그 뒤는 종반입니다. 오답노트 목록 위에서 단계를 고르면 그 단계 문제만 보이고, 오늘 복습·전체 풀기도 그 단계 문제만 풉니다. 학습방의 오답노트 칸에서도 단계별로 바로 열 수 있습니다.
  • 답을 고른 뒤 — AI 후보수가 나타나고, 처음 둔 수는 빨간 ✕, 내 답은 동그라미로 표시됩니다. 후보수에 마우스를 올리면(폰은 길게 누르면) 수순이 보입니다. 아래 칸에 메모를 적어 두면 문제와 함께 저장됩니다.
  • 복습 일정 — 맞히면 1·3·7·14·30·60일 뒤에 다시 나오고, 틀리면 바로 복습 목록에 남습니다. 오늘 복습은 날짜가 된 문제만, 전체 풀기는 모든 문제를 냅니다. 문제를 누르면 그 문제만 풉니다.
  • 그만하기를 누르면 풀기 전에 보던 기보로 돌아갑니다. 푸는 동안에는 GPU 분석을 멈추고, 다른 기기의 바둑판도 바꾸지 않습니다.

기보 불러오기(한큐바둑)

기보 불러오기에서 한큐바둑(野狐) 닉네임을 검색하면 최근 대국 약 100판이 나옵니다. 줄을 누르면 그 판이 바둑판에 열리고, 대국자·단·결과·날짜가 왼쪽 대국 정보에 채워집니다.

타이젬 개인 기보는 타이젬의 보호 장치 때문에 불러올 수 없습니다. 타이젬 프로그램에서 SGF로 저장한 뒤 SGF 열기를 쓰세요.

여러 기기에서 함께 보기

한 계정의 분석 판은 하나입니다. 노트북에서 GPU를 켜고 분석하다가 같은 계정으로 폰에서 분석 화면을 열면, 노트북 화면과 같은 판이 뜨고 서로 따라 움직입니다. 기기 수 제한은 없습니다.

  • 한쪽에서 두거나 수를 넘기면 다른 기기도 같은 수로 갑니다.
  • 실시간 분석은 판마다 하나만 돕니다. 어느 기기에서든 켜고 끌 수 있고, 분석을 돌리던 기기가 나가면 남은 기기가 이어받습니다.
  • 연결 상태에 지금 붙어 있는 기기 N대가 보입니다(가로 화면은 위쪽 막대, 폰은 ☰ 메뉴 맨 위 GPU 칸).
  • 폰에서 열 때는 폰 브라우저로 사이트에 로그인한 뒤 GPU 대여 화면의 분석 화면 열기를 누르세요.

  • 비밀번호 변경 — 현재 비밀번호를 확인한 뒤 바꿉니다(8자 이상).

  • 회원 탈퇴 — 켜져 있는 GPU를 먼저 끄세요. 남은 잔액은 돌려받을 수 없으니 환불이 필요하면 탈퇴하기 전에 관리자에게 요청하세요.

자주 묻는 질문

“분석 화면 열기”가 안 나타나요.

보통 1~3분 걸립니다. 목록에서 ⚡빠른 시작이 붙은 GPU는 최근에 써 본 서버라 더 빨리(보통 1분 안팎) 켜집니다. 처음 쓰는 서버는 프로그램을 내려받느라 1~2분 더 걸릴 수 있습니다. GPU 대여 화면의 세 단계 중 어디까지 왔는지 보세요. 너무 오래 걸리면 GPU가 스스로 꺼지고 “실패”로 표시됩니다. 그때는 다른 GPU를 골라 다시 시작하세요.

연결이 끊겼다고 나와요.

폰 화면이 꺼지거나 네트워크가 바뀌면 잠깐 끊겼다가 자동으로 다시 붙습니다. 화면으로 돌아오면 바로 연결을 확인하고, GPU의 접속 주소가 바뀌어도 사이트에 로그인된 브라우저는 새 주소로 알아서 옮겨 붙습니다. 계속 끊겨 있으면 GPU 대여 화면에서 GPU가 아직 “사용 가능”인지 보세요. 10분 동안 쓰지 않아 자동으로 꺼졌을 수 있습니다.

분석이 느려요.

위쪽 막대의 visits/s를 보세요. 자동분석이나 대국 리포트가 도는 동안에는 GPU를 나눠 쓰므로 실시간 분석이 느려집니다. 더 빠른 GPU(5070 Ti, 5090 등)나 작은 모델을 고르면 빨라집니다.

탭을 닫았는데 요금이 나가나요?

탭을 닫아도 GPU는 켜져 있다가 10분 동안 분석 요청이 없으면 스스로 꺼집니다. 그 사이의 요금은 나가니, 다 썼으면 GPU 종료를 누르세요.

분석 결과를 나중에 다시 보고 싶어요.

위쪽 막대의 내 기보 저장을 쓰세요. 분석값이 함께 저장돼서 처음 화면의 '내 기보'에서 GPU를 켜지 않아도 그래프와 후보수를 볼 수 있습니다(새로 분석하려면 GPU가 필요합니다). 내 기기에 파일로 두려면 SGF 저장을 쓰면 됩니다.

YZY와 결과가 조금 달라요.

모델과 탐색량(visits)이 같아야 결과가 비슷합니다. 특히 손해 집 수와 등급은 분석 조건에 따라 달라집니다. 같은 모델을 고르고 세기를 보통(500 visits)으로 맞춰 비교해 보세요.
